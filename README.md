# LinkGroupz 배포 파일

자주 여는 웹 페이지를 그룹으로 묶어 두고, 메뉴바(Windows 는 트레이)에서 Chrome 이나 Edge 에 한 번에 여는 앱 **LinkGroupz** 의 설치 파일을 올려 두는 곳입니다.

## 받기

[**최신 버전 받기**](../../releases/latest)

| 운영체제 | 받을 파일 |
|---|---|
| macOS (Apple Silicon) | `LinkGroupz-<버전>.dmg` |
| Windows 10 · 11 (64비트) | `LinkGroupz-<버전>-setup.exe` |

`…app.tar.gz` 와 `latest.json` 은 앱이 스스로 업데이트할 때 쓰는 파일이라 직접 받을 필요가 없습니다.

## 처음 열 때

- **macOS**: DMG 를 열어 LinkGroupz 를 Applications 로 옮긴 뒤 엽니다. "'LinkGroupz'을(를) 열지 않음" 경고가 뜨면 **완료** 를 누르고, **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기** 를 한 번 누릅니다 (Apple 공증을 받지 않은 앱이라 뜨는 경고입니다).
- **Windows**: 설치 파일을 실행합니다. **Windows 의 PC 보호** 창이 뜨면 **추가 정보 → 실행** 을 누릅니다 (서명하지 않은 설치 파일이라 뜨는 창입니다).

## 업데이트

설치한 뒤에는 앱이 1시간마다 이곳의 새 버전을 확인해 알려 줍니다. 내려받은 파일은 서명을 확인한 뒤에만 설치합니다.
